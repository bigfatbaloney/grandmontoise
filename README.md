# La Grandmontoise – Comité de programmation

Application web interne pour le comité de programmation de La Grandmontoise (Saint-Gédéon, Lac-Saint-Jean).

## Fonctionnalités

- 🎭 Gestion des spectacles (checklist, tâches, notes, liens)
- 📅 Calendrier de la saison
- 📁 Accès Google Drive du comité
- 🔧 Liens et ressources utiles

## Installation sur Replit

1. Crée un nouveau Repl en choisissant **"Import from GitHub"**
2. Colle l'URL de ce repo
3. Dans le terminal Replit, lance :

```bash
npm install
npm run dev
```

4. Replit va démarrer l'app et te donner une URL publique.

## Structure des fichiers

```
grandmontoise/
├── index.html
├── package.json
├── vite.config.js
├── tailwind.config.js
├── postcss.config.js
└── src/
    ├── main.jsx
    ├── index.css
    └── App.jsx        ← code principal de l'app
```

## Partage avec le comité

Une fois déployée sur Replit, partage simplement l'URL avec les membres du comité.
Aucune installation requise de leur côté — ça fonctionne dans n'importe quel navigateur.
